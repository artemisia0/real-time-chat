## Overview
This project is a **real-time chat web application** designed to demonstrate full-stack concepts including authentication, chat management, user permissions, and real-time messaging. The focus is on functionality, interactivity, and responsive design.

---

## Features
- User authentication: sign up, sign in, and sign out  
- Create, rename, and delete chat rooms  
- Add and remove users from chats, with permission control  
- Edit and delete own messages  
- Responsive and user-friendly design for multiple screen sizes  

---

## Tech Stack

### Frontend
- Next.js  
- Apollo Client with WebSockets (GraphQL client)  
- Jotai (state management)  
- DaisyUI (UI components and styling)  
- iron-session (session management)

### Backend / Infrastructure
- Separate backend API server: `real-time-chat-api` repository, deployed independently

---

## Implementation Notes
- Frontend and backend are deployed separately  
- Demonstrates real-time communication, state management, and user authentication workflows  

---

## Purpose
This project was built as a **learning and portfolio application** to practice real-time chat, user management, and full-stack development. It is not intended for production use.
